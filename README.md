Graphical Password Authentication System

A secure and interactive graphical password authentication system built with Python and Tkinter. Users select points on a background image to create a unique password, which is validated with a tolerance-based matching algorithm. Upon successful login, users can submit personal details through a form with real-time validation.

✨ Features





Graphical Password: Click points on an image to set and authenticate a password.



Responsive UI: Clean Tkinter interface with colorful buttons and feedback.



Form Validation: Real-time validation for user details (Name, USN, Contact).



Success Notifications: Visual confirmation for successful login and form submission.



Secure Matching: Tolerance-based algorithm for password verification.

🛠️ Tech Stack





Python: Core programming language.



Tkinter: GUI framework for building the interface.



Messagebox: User feedback for errors and success.

🚀 Getting Started

Prerequisites





Python 3.x



Tkinter (included with Python)



A background.gif image in the project directory

Installation





Clone the repository:

git clone https://github.com/yourusername/graphical-password-authentication.git
cd graphical-password-authentication



Ensure background.gif is in the project root.



Run the application:

python main.py

🎯 Usage





Launch the app and click points on the image to set your graphical password.



Click Save Password to store it.



Click Login to authenticate using the same points.



On successful login, fill out the form with Name, USN, and Contact Number.



Submit the form to receive a verified authentication confirmation.
